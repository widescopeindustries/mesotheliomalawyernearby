# Test Directory

This directory mirrors the `/src` structure for testing purposes.

## Structure

```
tests/
├── components/     # Component tests
├── lib/           # Utility function tests
├── app/           # Page and route tests
└── README.md      # This file
```

## Testing Standards

- All components should have corresponding test files
- Follow the naming convention: `ComponentName.test.tsx`
- Ensure 80%+ code coverage for critical paths
- Use TypeScript strict mode
