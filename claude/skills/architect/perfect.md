# Mesothelioma Lawyer Nearby - Project Guide

## Tech Stack & Environment
- **Framework:** Next.js (App Router) / Programmatic SEO Framework
- **Automation:** Python-based OpenCode for geo-entity generation
- **Styling:** Tailwind CSS (Mobile-First, Professional/Legal Aesthetic)
- **Hosting:** Vercel
- **Authority Focus:** SDVOSB (Veteran-Owned) Trust Signals

## Precise Coding Standards
- **File Naming:** kebab-case for all files (e.g., `location-page.tsx`).
- **Components:** Use Functional Components with TypeScript interfaces.
- **SEO Rules:** Every new page MUST have a unique `Metadata` object with a targeted location keyword from our Ahrefs data.
- **Lead Gen:** All forms must include the "FCC Compliant" disclaimer and the "Veteran/Loved One" radio toggle.

## Project Structure
- `/app/location/[state]-[city]`: Programmatically generated local lead pages.
- `/app/api/leads`: Python-integrated endpoints for lead distribution.
- `/components/trust`: Specific section for SDVOSB and Veteran badges.
- `/content/veteran-resources`: Markdown-based articles for veteran asbestos exposure.

## UI/UX "Perfect" Guidelines
- **Color Palette:** Professional Navy (#002147), Gold/Bronze accents for Veteran badges, White space for readability.
- **Typography:** Serif for headers (Trust/Authority), Sans-serif for body (Readability).
- **CTA Rule:** "Click-to-Call" buttons must be primary (Gold/Bronze) and sticky on mobile.
